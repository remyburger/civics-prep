# Civics Prep

A study app for the USCIS 2025 Naturalization Civics Test (128 official questions,
20 asked at interview, 12 correct needed to pass).

- **Practice** — flashcard quiz, weighted toward questions you haven't mastered
- **Interview** — mock interview simulating the real 20-question / pass-at-12 / fail-at-9 format
- **Browse** — full searchable reference list of all 128 questions and accepted answers
- **Settings** — personalize the answers to time-sensitive questions (current President,
  your state's senators, etc.)

Progress is tracked per-question in your browser's local storage — nothing leaves the device.

Built with React + Vite, deployed to GitHub Pages via GitHub Actions on every push to `main`.
